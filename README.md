# Shadow of the Watchers

A browser-based, StarCraft-style asymmetric RTS set in a mythic pre-flood world of
fallen Watchers, giant clans, and bronze-age city-states. Built with Three.js + Vite.
No copyrighted game IP — only the genre's bones: worker economy, fog of war, tech
trees, asymmetric factions, and an AI that comes for your base.

## Play

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

Deploy anywhere static. For Vercel: `npx vercel deploy --prod` from the repo root
(framework preset: Vite). The build output is `dist/`.

## Factions

| | The Covenant Cities | The Watcher Remnant | The Nephilim Clans |
|---|---|---|---|
| Identity | Priest-king city-states | Fallen angels' disciples | Giant-blooded raiders |
| Strength | Balanced eco, defense, counters | Elite units, forbidden tech | Brutal melee, base-breaking |
| Weakness | Slow to the supernatural | Expensive, slow economy | Weak economy, costly pop |

All three factions are fully playable; the AI plays a random different faction.

## Resources

- **Grain** 🌾 / **Timber** 🪵 / **Bronze** ⚒ — gathered by workers from map nodes
- **Divine Favor** ✦ — generated by temples and main halls
- **Forbidden Knowledge** 𓂀 — harvested from graven obelisks at the map's center passes.
  The obelisks are guarded. Bring soldiers, or bury your workers.

## Controls

- **Left-click / drag** — select units (drag-box prefers soldiers over workers)
- **Right-click** — move / gather / attack / set rally / resume construction
- **A** — attack-move · **S** — stop · **B** — build menu (workers) · **Esc** — cancel
- **Ctrl+1–9** — assign control group · **1–9** — recall group
- **Arrows / screen edge** — pan · **Wheel** — zoom · **Q/E or middle-drag** — rotate · **H** — go home
- Right-click the minimap to order moves; left-click/drag it to pan the camera

Win by destroying the enemy's main hall. Lose yours and the flood takes the rest.

## Architecture

```
src/
  data.js         factions, units, buildings, upgrades, resource defs (all lore lives here)
  models.js       procedural low-poly meshes — dark stone bodies + faction glow accents
  terrain.js      seeded map generation, walkability grid, fog of war (shader-multiplied)
  pathfinding.js  grid A* with octile heuristic + line-of-sight smoothing
  game.js         engine: entities, orders, combat/counters, economy, production, win/loss
  ai.js           enemy AI: build order, eco management, scouting, defense, attack waves
  controls.js     RTS camera rig, selection, command input, building placement ghosts
  ui.js           resource bar, minimap, command card, health bars, toasts
  audio.js        WebAudio synth (no assets): clicks, hits, alerts, win/lose stingers
  main.js         menu, faction select, game lifecycle
```
